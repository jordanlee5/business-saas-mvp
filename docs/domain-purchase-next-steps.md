# 公司域名、备案与 HTTPS 配合清单

记录日期：2026-11-09。服务器已购、公司主体与腾讯云企业认证已完成；后台测试验收及本轮界面 / 导出更新完成。域名尚未选定或购买，当前仍走本机受限入口；没有开启公网网站、没有提交微信审核。

## 现在只做候选与费用核对

1. 使用购买服务器的同一个企业腾讯云账号，打开 [腾讯云域名注册](https://buy.cloud.tencent.com/domain)。
2. 用公司品牌的英文或拼音准备 2–3 个候选，先查询普通 `.com` / `.cn`。先选一个主域名即可；测试后台和小程序接口可用它的不同子域名，不必分别买多个主域名。避开二手交易、白金域名等高价选项。
3. 先按 1 年查看，核对完整拼写、可注册状态、首年费用、第二年续费价、购买年限、自动续费及附加项目。候选与实时费用尚未取得，不能把历史广告或搜索结果报价当成本账号订单价。
4. 若提示创建域名实名信息模板，选企业模板，使用已确定的实际运营公司；企业账号实名和域名实名模板是两个步骤。营业执照及负责人材料只提交官方控制台，不提交聊天或 Git。
5. 把候选及价格页给开发方核对，个人证件、联系方式打码。核对完成前不支付，不购买建站套餐、付费 DNS、收费 SSL 证书或备案代办。

[腾讯云官方注册步骤](https://cloud.tencent.com/document/product/242/9595)要求查询可注册性、使用已实名的信息模板，并在支付前核对域名、时长和费用。[域名价格表](https://buy.cloud.tencent.com/domain/price)供对照，最终以当前账号确认页为准。

## 购买后按顺序配合

- 域名注册 / 实名完成后，按上海企业实际情况准备网站备案材料；在腾讯云填写真实的网站用途、主体及负责人，按页面完成材料和核验。仍需核对小程序主体是否一致，不混用两家公司的资料。
- 备案具体流程和材料按当时控制台及 [官方备案指引](https://cloud.tencent.com/document/product/243/39038)核对；不能承诺固定完成日期。公开网站启用前完成所需备案。网站和小程序的备案 / 发布是不同事项，本轮不自动提交小程序审核。
- 备案和域名条件就绪后，开发方配置测试子域名解析、现有 Caddy HTTPS 入口，核验证书、续期、后台登录和带身份图片访问。当前无须先买收费证书；真正签发须有可用域名和验证通路。
- HTTPS 可用后，再核对微信合法域名、真实手机测试与物流服务商联调。真实业务库仍保持只读，生产切换另行安排。

当前待用户提供：候选品牌 / 拼音或 2–3 个域名，以及候选查询页的首年与续费费用。未购买任何域名或额外云服务。
