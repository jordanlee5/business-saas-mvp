# M7-25 小程序多条权益领取与激活后查看积分

同一会员可以持有多条独立积分批次。个人中心的激活入口对访客和已登录会员均可见；是否可以领取某条业务，仍由 M7-22 服务端按微信身份、业务匹配信息、一次性激活码和领取截止时间判断。小程序不根据本机登录状态跳过安全因子，也不在本机保存激活信息。

激活成功只表示服务端已提交积分入账。成功页提供由用户主动点击的“微信登录并查看积分”：客户端重新调用 `wx.login`，通过现有会员会话接口取得短期令牌并确认会员身份，随后进入积分页，由积分页从服务端重新读取汇总、批次和流水。激活时消耗的微信一次性 code 不被复用；没有自动登录、自动重试激活或本地持久化令牌。用户也可以返回个人中心。

若新的会员登录失败，页面仍保留“激活成功”事实，只显示登录错误，允许用户再次主动登录或返回个人中心；不会再次提交激活请求。离开页面时清空业务单号、手机号、车牌和激活码；若登录仍在进行，则清除本机临时会话并忽略过时结果。小程序不在日志、URL 或本地存储中记录激活码、微信 code 或令牌。

微信开发者工具验收包括访客与已登录两种入口、激活页输入清除、成功后的主动登录按钮、登录失败时不重复激活，以及页面离开时的过时响应忽略。真实正向激活与积分展示仍需正式 AppID、AppSecret、HTTPS 合法域名、可用且安全交付的一次性码和已承接商城业务；条件不具备时记为 `DEFERRED`，不能用模拟请求冒充真机验收。本轮没有服务端或数据库变更。
