# M7-12 小程序导航与访客页面视觉整理

商城目录、我的积分和个人中心使用三项底部导航；只有已实现的目的地才出现。当前项以品牌绿文字和暖金细线标明，页面主体为底栏和安全区留出空间。商品详情保留原返回路径，避免在规格选择时被底栏切走。三个页面之间使用 `reLaunch`，防止往返操作积累页面栈。

参考图用于学习导航层次与留白，不复制其中的商标、商品图、品牌分类或购物车。真实目录为空时保持现有空状态，不制造测试商品。访客积分和个人中心仍不展示余额、订单、手机号或登录成功态，也不调用会员私有 API。

本轮只改变前端导航和展示：无数据库迁移、后端接口、真实微信登录、积分激活或真机发布。微信开发者工具只在同机开发模拟器验收；正式 AppID、HTTPS 合法域名和身份服务就绪后再单独验收真机及会员数据。
