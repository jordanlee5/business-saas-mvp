# 小程序导航与访客页面视觉整理（M8-2更新）

商城目录、购物车、我的积分和个人中心使用四项底部导航，共用 `templates/mall-nav.wxml`。当前项以浅绿底、品牌绿图标文字和暖金短线标明，页面主体为底栏和安全区留出空间。商品详情保留原返回路径，避免在规格选择时被底栏切走。四个一级页面之间及详情进入购物车使用 `reLaunch`，防止往返操作积累页面栈。购物车进入商品详情仍使用 `navigateTo`，返回时刷新公开商品详情。

视觉沿用深绿与暖金，统一图标、卡片、标题和留白，不复制参考图的商标、商品图或品牌分类。真实目录为空时展示空状态，不制造测试商品。访客积分和个人中心仍不展示余额、订单、手机号或登录成功态，也不调用会员私有 API。购物车沿用M8-1本机草稿规则；合计随列表滚动，不与底栏叠放。

本轮只改变前端导航和展示：无数据库迁移、后端接口、真实微信登录、积分激活或真机发布。微信开发者工具只在同机开发模拟器验收；正式 AppID、HTTPS 合法域名和身份服务就绪后再单独验收真机及会员数据。
