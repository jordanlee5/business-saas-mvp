# M7-11 小程序会员访客入口

商城首页增加“我的积分”和“个人中心”入口。未接入微信身份及安全会话之前，这两页始终展示访客状态，不显示余额、积分批次、流水、手机号或任何虚构的会员身份，也不调用会员私有 API。访客余额不能解释为零。

个人中心显示登录与激活尚未开放，积分中心引导返回商城或查看个人中心。两个页面支持从首页进入、相互跳转与返回商城。公开目录和商品详情仍使用现有只读接口，开发者工具环境门禁沿用 M7-10。

本切片没有登录按钮、`wx.login`、授权弹窗、会话令牌或会员写接口。后续接入真实微信登录时，必须在服务端用 code 换取微信身份，并验证会话、绑定关系与授权范围，再开放会员积分查询；不能以静态页面或小程序端变量当作身份凭证。
