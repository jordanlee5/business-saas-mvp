# M7-23 小程序权益激活页

访客从个人中心主动进入激活页，输入公开业务单号、业务登记手机号、车牌号及上传方安全交付的一次性激活码。前端仅作长度和基本格式校验；真正的资格、身份、安全因子和错误次数以服务端 M7-22 接口为准。仅点击提交时取得新的微信一次性 code，再调用 `POST /api/miniprogram/v1/activation/redeem`。无自动重试、无本地持久化、无敏感值日志、无请求体回显。

成功只接受 `status=activated`，清除页面输入后提示回个人中心用新的 `wx.login` 建立短期会话；激活所用 code 不复用。失败统一展示安全的通用提示，清除激活码。离页清除所有输入并忽略过时的请求结果。网络中断可能导致服务端已提交而客户端未收到响应，用户应先核对结果，不能自动重试。

本轮只接入客户端。运营签发及安全交付入口、正式 AppID/AppSecret、HTTPS 合法域名、网关限流和真机正向激活需另行验收。没有真实凭据时只能验证表单本地拒绝、配置门禁和服务端受控失败，不能记录真实激活为通过。
