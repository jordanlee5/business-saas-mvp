# M7-8 微信小程序商品规格选择

商品详情页从现有公开只读接口取得已启用 SKU 的价格与库存状态。初次加载展示最低积分价与商品整体是否有货；点击某一规格后，显示该规格的积分价、库存状态和“已选”标识。无货规格仍可查看，页面不开放兑换或下单。下拉刷新、失败重试重新读取服务端详情；若已选规格仍存在，更新其最新价格与状态，若已不再公开则清除选择。商品下架或不存在时沿用 404 状态。

本切片只改小程序详情页，不增加服务端写接口、迁移或模拟库存。库存提示是查询时的快照，之后的订单交易仍须由服务端重新核验。真实目录为空时只能验证 404、断网和恢复；规格交互应在已有上架商品，或隔离数据库副本中通过管理员页面建立的公开商品上验收。草稿商品不会进入公开目录；上架须有启用分类、启用供应商及至少一个启用 SKU。图片和库存余额不是公开可见的必需条件，未入库时 SKU 将显示“暂时无货”。不要为验收向真实业务库写入临时数据。
