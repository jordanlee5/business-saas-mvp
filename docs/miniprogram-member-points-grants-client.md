# M7-19 小程序会员积分批次列表

“我的积分”页沿用运行内存中的短期会员会话，先通过 `/auth/me` 确认当前身份，再读取积分汇总与 `GET /api/miniprogram/v1/points/grants?page=1&page_size=20`。两项数据与格式均有效后才显示会员编号、汇总和批次。访客不调用任何会员私有接口，也不把未知余额显示为 `0.00`；真正的零余额以服务端的 `0.00` 展示。

批次按服务端顺序分页，每页最多 20 条。仅展示初始、可用、预占积分，状态、激活与到期北京时间；不显示来源业务、姓名、电话或其他会员信息。空列表明确显示“当前没有积分批次”。有后续页时由会员主动点击加载更多，不预取；最后一页不再请求。

401 清理本机令牌。网络、503、格式异常或分页失败时隐藏当前页所有会员积分与批次，提供重新加载入口；页面离开、会话清理或更替后旧响应不能回写。令牌与微信 code 不进入页面状态、本地存储或日志。本轮不改服务端 API、数据库、积分账本、微信登录和激活行为。

临时测试号、无合法 HTTPS 域名和已绑定会员时，只能验收访客页、公开目录、无令牌 401 和后台权限回归。真实会员批次与分页正向验收记录 `DEFERRED`，不得用模拟数据宣称通过。
