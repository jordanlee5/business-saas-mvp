# M8-1 小程序购物车草稿

商品详情页只能把真实公开接口返回、已选且当前有货的 SKU 加入购物车。购物车在本机保存商品公开编号、SKU 编码和数量，不保存价格、姓名、手机号、地址、会员身份或微信登录凭据。最多 20 款规格，每款 1–99 件；重复加入增加数量，越界时拒绝。存储内容异常时失败关闭，不静默改写。

每次打开购物车、手动刷新或修改数量，客户端重新请求公开商品详情，展示当前价格及库存状态；下架、停用、不可见或无货的规格明确标示，且不计入当前参考合计。价格按两位小数字符串转整数分位计算。购物车中的可用状态和参考合计都不是下单承诺，后续订单服务仍须在原子事务中重新核验会员身份、商品、库存、积分批次与价格。

本切片不提交订单、不预占积分或库存、不写真实业务库、不建立地址及物流信息。正式 AppID、微信平台隐私保护指引与 HTTPS 合法域名仍待配置；访客可以整理本机购物车，但不能凭购物车绕过 M7-26 的会员隐私门禁。真实目录为空时，开发者工具只验收空购物车页面和公开目录，不向业务库制造演示商品。
