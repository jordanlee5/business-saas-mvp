# M7-21 小程序会员积分流水页

“我的积分”仅在已有内存会员会话时依次读取 `/auth/me`、`/points/summary`、`/points/grants?page=1&page_size=20`、`/points/ledger?page=1&page_size=20`。四项成功且响应形状正确后才显示当前会员的汇总、批次和流水。流水的“加载更多”固定每页 20 条，独立于批次分页；每项只显示类型、可用积分变化、预占积分变化及北京时间。正负变化量按服务端原样显示，不自行推算余额。

访客不调用会员私有接口、`wx.login` 或登录交换，不显示虚构的 `0.00`。分页参数、响应字段、时间和积分变化量均经过客户端检查；401 清除内存会话，网络或数据错误隐藏旧私有信息并显示重试。页面离开、卸载或会话更替后的旧响应不会回写。令牌仍只保存在运行内存，页面不记录或持久化令牌。

本轮不改变服务端接口、数据库结构和权限，也不支持积分消费、权益激活或真机上线。没有合法 AppID、HTTPS 域名及已绑定真实会员时，微信开发者工具只验收访客无私有请求、公开目录和既有后台权限；会员正向流水及分页记为 `DEFERRED`。正向服务端接口行为已由 M7-20 的 SQLite/独立 PostgreSQL 测试覆盖，不能替代真实会员页面验收。
