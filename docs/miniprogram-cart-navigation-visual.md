# M8-2 购物车底部导航与视觉整理

沿用现有自绘底栏，将四个一级入口固定为“逛好物、购物车、我的积分、个人中心”。四页共用 mall-nav WXML 模板，当前项用浅绿底、深绿图标文字和暖金短线标明；当前项不可重复点击。入口延续 reLaunch，不累积一级页面栈。商品详情查看购物车也使用 reLaunch；购物车点商品仍进入详情页，详情返回购物车时继续触发 onShow 读取公开详情。

深绿、暖金和浅暖背景贯穿四页，统一卡片、标题、留白、空态与导航图标。商城原中部“查看购物车”入口移入底栏。购物车整理空态、错误态、规格卡、数量控件和参考合计；合计随内容滚动，四页统一保留160rpx加底部安全区，避免底栏遮挡内容。商品名、规格与长积分值可换行。积分页同步移除“权益激活将在后续阶段接入”的过时文案。

购物车存储格式、20种规格/1–99件限制、公开详情刷新和无货项排除合计均沿用M8-1。未新增后端接口、数据库结构、登录行为、地址、下单或扣减。导航不自动登录；会员页仍按现有会话和微信隐私授权规则工作。不会为视觉效果填充商品、积分余额或会员资料。

验收：四页底栏顺序和当前项；多次往返页面栈不增长；空目录和空购物车；窄屏及带安全区机型无重叠；已有搜索、积分和个人中心入口；公开浏览无会员/激活/订单请求；临时副本编译及关闭前恢复域名设置。真实公开目录为空时商品加入、增减、移除和重取详情记DEFERRED，禁止向真实业务库制造商品。正式AppID、平台隐私正向、HTTPS域名、真机及真实会员正向继续按条件独立验收。
