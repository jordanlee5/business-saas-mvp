# 备份接收主机迁移与后台无窗口运行

## 当前主机弹窗修正（2026-11-13）

本机每小时异机拉取和每5分钟外部只读巡检原先直接使用 `python.exe`，Windows 登录会话会出现控制台窗口。现在两个任务均使用同目录 `pythonw.exe`；SSH 子进程指定 `CREATE_NO_WINDOW`。标准输入输出缺失时接到空设备，原有 `last-run.json`、`state/latest.json` 和任务退出码继续用于判断成功/失败，不把隐藏窗口当作执行成功。

安装器同步采用无窗口入口，缺少 `pythonw.exe` 或 Windows OpenSSH 客户端时提前拒绝。既有任务仅修改启动可执行程序，参数、工作目录、运行用户、登录/定时触发、超时及重复任务处理均保持；任务 XML 与旧运维代码另存私密新目录供回退。未停止运行中任务、手动触发真实拉取/轮换、访问业务库或修改云端。

本轮验证及自然运行结果见[脱敏证据](validation/windows-background-tasks-20261113.json)。任务为用户登录会话模式，关机、睡眠、注销仍不能运行；锁屏可运行。无窗口不等于无网络或磁盘占用。

## 换另一台电脑是否需要整套业务环境

可以更换。以下为 **Windows 接收主机** 的最小条件，不代表已经完成新主机验收：

| 项目 | 用途 |
| --- | --- |
| Python 及同目录 pythonw.exe | 执行和无窗口启动运维脚本；本轮使用 Python 3.12.14 并关闭第三方 site 包验证接收/巡检代码 |
| Windows OpenSSH 客户端 | 经 SSH 连接服务器，严格核对服务器指纹 |
| Windows 任务计划程序 | 每小时及登录补拉；如迁移巡检则另设每5分钟任务 |
| 独立私密目录、足够磁盘空间、联网 | 保存最近14个校验通过的完整副本；异常副本保留，因此14不是磁盘上限 |
| 已授权 SSH 登录凭据、核验过的 known_hosts | 私下配置，不能贴聊天或提交 Git；服务器侧保留导出/回执所需权限 |

只接收、校验密文不需要 SaaS 应用、数据库、Docker、WSL、微信开发者工具，也不需要解密私钥或第三方加密库。密文清单及摘要校验不等于认证解密验证。将来若在新电脑执行解密或恢复，再单独准备加密库、离线密钥、精确版本镜像和恢复环境。SSH 登录私钥与备份解密私钥是不同用途的凭据。

新电脑不必安装 Codex。应使用新电脑自身稳定的 Python 路径，不照抄旧电脑缓存路径；正式安装前确认版本兼容和全部检查通过。Linux 主机也可使用接收脚本，但当前两个安装器仅适用于 Windows，定时服务需另行配置验证。

## 到时按这个顺序迁移

1. 告知新电脑的操作系统、准备存放备份的磁盘和大致开机时段；先检查空间和必要组件，再在不影响该电脑测试/工作时补齐。使用现有电脑不需要购买短信或云存储服务。
2. 新建专用私密目录，用 `install-offsite-pull.ps1` 安装；配置 SSH 身份和已核验服务器指纹，不复制旧电脑的整份私密目录，不带入业务密码、Webhook 或备份解密私钥。安装器拒绝覆盖既有目录/同名任务。
3. 在新电脑完成第一次完整拉取，核对恢复点编号、密文/清单摘要、本机成功记录及服务器回执。验证失败保留旧任务。拉取本身不会停止云端应用，但成功回执会沿用既有云端7点、本机14点保留策略，迁移当天须检查删除候选与异常保留点。
4. 验证新电脑自然定时或重新登录后的自动补拉，再停用旧电脑的小时任务。外部巡检是另一个任务，要一起迁移或明确保留在哪台电脑，避免旧电脑仍每5分钟运行。
5. 旧电脑备份原样保留，新电脑默认只补最新点，不自动搬运所有历史恢复点。若要搬历史点，另行校验并安排；不要因迁移完成立即清空旧盘。离线密钥副本继续独立妥善保管，旧电脑退役前另外核对密钥可恢复性。

当前服务器成功回执表示最近一次成功接收，不是逐主机统计；不能仅看云端已有绿色状态认定新主机通过。切换须以新主机自身日志、完整性校验和对应回执共同判断。

## 关机影响

新主机接管后，旧主机关机不影响服务器自动加密备份，也不影响新主机的拉取。新主机自己关机/睡眠/注销时无法拉取，恢复联网并登录后补拉最新点；按当前配置，备份来源或成功回执过期36小时会由云端巡检告警。服务器自己的告警与电脑巡检不同：当前电脑外部巡检只记本地状态，没有新增对外消息通知。

## 必要时回退启动方式

私密安装目录中 `quiet-launch-20261113-112946` 保存修改前后 XML 和旧代码，仅运维文件，无恢复点。回退前等待任务空闲，只恢复对应任务原启动可执行程序和必要的运维文件，核对原触发/设置保持；不要删除副本目录或覆盖业务数据。恢复旧 `python.exe` 会重新带来窗口，通常应修复无窗口方式而非长期回退。
