# 会员积分查看与导出说明（M3-5）

## 1. 功能范围

管理员登录后可从侧边栏“积分商城 → 会员积分”进入 `/member-points`。本功能只提供内部查询与单会员 Excel 对账，不是会员端积分接口。

- 列表：按会员状态筛选，并可使用会员公开编号、来源业务单号、姓名、手机号或车牌号检索；
- 详情：查看账户缓存余额、账户版本、独立积分批次、到期时间和不可变流水；
- 对账：每次读取都会比较账户缓存、全部批次缓存与流水重算结果；异常仅提示，不自动覆盖；
- 导出：生成单个会员的汇总、积分批次和积分流水工作表。

查询不会执行积分到期任务，不会改变批次状态，也不会提前实现积分预占、消费或退款。

## 2. 权限

| 账号类型 | 查看列表与详情 | 导出 Excel |
| --- | --- | --- |
| 超级管理员 | 允许 | 允许并记录审计 |
| 运营管理员 | 允许 | 允许并记录审计 |
| 初审管理员 | 拒绝 | 拒绝 |
| 复核管理员 | 拒绝 | 拒绝 |
| 上传方 | 拒绝 | 拒绝 |
| 停用、空级别或未知级别账号 | 拒绝 | 拒绝 |

权限同时作用于导航入口和服务端路由。隐藏菜单不代替服务端检查；操作者身份只取当前已认证会话。

## 3. 隐私与导出边界

页面中的来源客户姓名、手机号和车牌号均为脱敏值。页面与 Excel 都不包含以下字段：

- 微信 `openid`、`unionid` 或小程序 App ID；
- 一次性激活码、盐、摘要、失败次数等激活凭据；
- 积分流水幂等键。

Excel 因对账需要包含来源客户姓名、手机号和车牌号，只能保存在受控位置。以 `=`、`+`、`-`、`@`、制表符或换行开头的文本会转义，防止打开文件时被当作公式执行。

## 4. 导出审计

每次成功生成 Excel 后，系统在提交响应前写入管理员操作日志：

- 动作类型：`mall_member_points_export`；
- 目标类型：`member`；
- 目标编号：内部会员 ID；
- 说明：会员公开编号、批次数、流水数、账本一致性和 UTC+8 生成时间。

日志表示服务端已生成导出，不证明浏览器最终保存了文件。工作簿生成、权限复核或日志写入失败时，导出日志整体回滚。

## 5. 异常处置

当页面显示“账本一致性异常”时：

1. 停止该会员相关积分写操作；
2. 保存页面和导出作为只读对账材料；
3. 使用既有流水审计能力定位账户或批次缓存漂移；
4. 未经独立审批不得直接改表或用查询页面自动修复。

“待到期处理”表示已到 `expires_at`，但批次仍保留未处理状态。应按 `docs/points-expiry-operations.md` 的默认只读流程检查，不应从本页面直接扣分。

## 6. 部署与验收

本切片不新增迁移，数据库 head 继续为 `0003_member_activation_security`。覆盖代码后至少执行：

```powershell
python -m compileall app migrations
python -m unittest -v test_member_points_service.py test_member_points_routes.py test_admin_permissions.py test_mall_governance.py
python -m unittest discover -v
```

页面冒烟应使用超级管理员或运营管理员验证列表、筛选、详情、脱敏显示、Excel 三个工作表及新增导出日志；再用初审或复核管理员确认菜单不可见且直接访问会返回工作台。
