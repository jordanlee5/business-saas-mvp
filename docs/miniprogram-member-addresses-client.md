# 会员地址客户端（2026-10-28）

从“我的—我的收货地址”进入，支持列表、新增、编辑、删除确认和显式设默认。六个字段手填，校验沿用 member-addresses.md；20条时仍允许编辑、删除和设默认。默认行为完全由服务端决定，删除默认不会自动选择其他地址。

地址仅存当前页面内存，隐藏/卸载清空；不进入路由参数、本地存储和日志。请求复用内存会员会话，检查会话代次，旧会话响应不能写回新页面。游客不发私有请求；401清除会话。写请求期间禁用重复操作；网络中断或不明确的结果禁止直接再次提交，要求刷新核对。422保留当前表单供修正。404/409要求重读列表。

不涉及数据库迁移、订单接口、正式AppID或隐私审核开关。自动化为模拟微信接口与隔离后端回归，不等于微信开发者工具或真实平台验收。原六项DEFERRED继续保留，本机独立PostgreSQL验收仍需准备。

## 可重复的客户端检查

使用已安装的 TypeScript 编译器将 miniprogram 输出到仓库外的临时目录，再执行 `node tests/miniprogram-addresses.cjs <编译输出目录>`。测试进程内替换微信请求及隐私授权，覆盖18组客户端行为；生产代码没有授权旁路。编译输出与测试日志不提交仓库。

在微信开发者工具集中验收时，检查“我的—我的收货地址”的游客提示，以及真实会员登录后的空簿新增、编辑、默认切换、删除确认、20条限制与往返刷新。真实登录仍受已批准隐私指引和平台环境约束，不通过修改审核标志绕过。
