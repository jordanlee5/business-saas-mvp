# 管理电脑外部只读监测（本地记录）

2026-11-12，从 `38fed35` 接续。现有服务器巡检无法在服务器整机断电时自行报告，新增管理电脑上的独立检查入口，补齐电脑在线期间的外部观察。**本轮仅保存本机状态，不新增企业微信或邮件提醒，未接触或复制Webhook。** 对外提醒与全天在线独立监测仍是后续待办，不将本轮称为完整外部告警闭环。

## 实际安装与行为

- Windows计划任务 `SaaS-Staging-External-Observer`，每5分钟及安装用户登录时检查；任务使用当前用户登录会话，最长2分钟，重复运行忽略。电脑需开机、联网且该用户已登录，锁屏可以运行，睡眠/关机/注销时停止，回来后补跑。不会唤醒电脑。
- 独立私密目录保存代码、连接参数和 `state/latest.json`、状态变化事件。目录ACL仅当前用户、SYSTEM和管理员可访问。复用原SSH可执行程序、私钥路径与已验证known_hosts文件；没有复制私钥，没有数据库或通知凭据。
- SSH严格校验主机身份，禁止交互认证，连接超时12秒、整个探测最多35秒。远端仅执行固定只读程序，读取已有巡检结果、服务器时钟和两个定时器状态。不会查询业务库、触发备份、执行容器操作或重启服务。
- 检查已有巡检是否超过15分钟未更新、状态是否异常、云端通知结果是否异常、两个定时器是否active，以及管理电脑与服务器时钟是否相差超过5分钟。
- 首次异常记录为 `pending`，连续两次观察异常才记录 `alert`；相同状态不重复写变化事件，恢复后记录 `ok`。间隔超过10分钟时重新开始连续计数，避免电脑一夜关机后沿用旧失败次数立即升级。
- SSH连接超时、网络中断、认证失败统一记录 `remote_unreachable_or_ssh_failed`，**不能据此断言服务器已经断电**。本机也断网时无法区分线路故障与远端故障。程序无通知发送器，不会在异常时自动向他人发送消息。

## 状态查看

```powershell
Get-ScheduledTaskInfo -TaskName 'SaaS-Staging-External-Observer'
# 私密安装目录中的 state/latest.json 保存最近一次外部检查结果。
```

状态文件中的 `checked_at` 是UTC时间，`status` 可为正常、待确认或异常；`outbound_notifications` 固定false。首次正常检查不发送任何消息。若检查进程本身或Windows任务无法启动，最近状态可能停留在旧值，须结合任务退出码和更新时间查看；本轮没有实现监测器自身的独立监督。

## 安装与暂停

```powershell
./deploy/staging-postgres/install-external-observer.ps1 `
  -PrivateRoot '<新的仓库外私密目录>' `
  -Python '<已有python.exe完整路径>' `
  -OffsiteConfig '<现有异机拉取私密config.json>'
```

安装器拒绝已有目录、同名任务和链接父目录，沿用现有连接参数，安装新任务，不修改原拉取任务。只支持当前 `saas-pg-test-cvm` 项目，远端读取路径固定，不能作为任意命令执行入口。本工具不读取或接收通知目的地配置。

```powershell
Disable-ScheduledTask -TaskName 'SaaS-Staging-External-Observer'
# 恢复本机检查
Enable-ScheduledTask -TaskName 'SaaS-Staging-External-Observer'
```

暂停仅阻止后续触发；不要终止正在运行的其他任务。保留私密状态记录，原云端备份、云端企业微信告警及本机小时拉取均继续按原设置运行。
