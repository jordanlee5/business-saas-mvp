# 后台导航、管理页面与 Excel 导出（2026-11-09）

- 左侧菜单在同一浏览器标签页内保留滚动位置；直接打开页面、刷新和前进后退时，当前栏目保持高亮且可见。仅调整菜单自身滚动，不推动右侧页面。浏览器禁用存储时仍将当前栏目显示出来。
- 供应商委托、会员浏览资格、会员权益申请统一为工作台样式：清晰的说明、状态、表单、操作留痕；权益详情并排展示办理记录和登记表单。
- 商城订单、会员积分、商品目录提供真正的 `.xlsx` 下载。导出当前已应用筛选的全部匹配记录，不限当前页。商品目录按商品 / SKU 展开，含待建 SKU 的草稿商品；会员积分导出汇总，单会员原有明细导出保留。
- 每次最多 10,000 条，超限明确提示缩小筛选，不截断文件。文件冻结表头、可筛选、积分与金额两位小数、时间标明北京时间。文本显式写为字符串，避免 Excel 将用户输入当作公式。
- 导出沿用对应模块的运营 / 超管权限，服务层再次校验；记录经办人、时间、类型和条数，不在日志中复制可能含个人信息的搜索词。不导出收货地址、微信身份和凭据。导出仅新增审计，不修改积分、订单或库存。
- PostgreSQL 导出使用同一可重复读快照，避免跨页期间更新造成列表前后不一致。
