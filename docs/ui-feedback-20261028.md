## 本轮：购物车缩略图

- 每张购物车商品卡的“有货”等状态标记下方、右侧空白处，增加128rpx方形圆角缩略图；左侧仍为规格及积分价，下方保留数量、移除和小计。
- 图片取当前商品详情的主图，沿用商品图片路径校验，不新增外部图床，不把图片写入本地购物车记录。点击缩略图进入对应商品详情。
- 下架、无图或加载失败时展示“暂无图片”占位，不阻断购物车核对或兑换；缺货商品仍可显示图片。
- 本轮仅实施这一项，首页导航、积分页和订单跳转在后续小轮调整。正式业务数据库没有更改，隐私审核标志继续为空。

## 积分展示实现边界

客户流水应与可用积分的增减一致。下单导致可用积分减少时记录一次商品兑换，内部预占转消费不再产生客户侧重复扣减；取消或退款分别以对应事件退回。账务及运营接口保留原始完整事件，不改变实际扣减时点。后续需同步处理分页、内部事件过滤和订单关联，避免简化后出现看似空白的流水页或金额不一致。

先完成本轮购物车小图，再做订单提交直达与交易页减负；随后精简积分页；最后合并实施四入口导航、分类页和首页8分类，使页面联动一次可验收。分类名称按下节用户确认清单实施，真实运营库的分类数据配置另行处理。
