# M7-5 微信小程序商品首页壳体

`miniprogram/` 是原生微信小程序 TypeScript 项目。首页调用现有公开只读分类及商品列表接口；分类切换、分页、下拉刷新、加载中、空状态和请求失败重试均读取真实响应。商品卡只用于展示，详情与会员登录在后续阶段接入，不提供假下单按钮。

开发者工具导入 `miniprogram/`。默认 `API_ORIGIN=http://127.0.0.1:8000` 仅用于同机模拟器访问本地 `uvicorn`；真实设备需可达的 HTTPS 服务、微信合法 request 域名和图片域名，并由后续部署阶段配置。不要把生产密钥、AppSecret、测试会员身份或真实库写操作放进小程序。默认保持合法域名检查，单机调试时可在开发者工具本地调试设置中临时关闭检查；正式预览须恢复检查并使用有效域名。

首页只展示已上架且启用分类、SKU 与供应商的目录；真实库空时显示“好物即将上架”。图片只接收商城媒体前缀路径；没有合法图片时使用文字占位。服务端可售状态仅用于展示，下单时仍应由事务重新核验。当前不依赖 npm 包，品牌颜色与间距先定义为本地样式，TDesign 组件、完整设计系统、会员身份和真机验收在后续独立切片接入。
