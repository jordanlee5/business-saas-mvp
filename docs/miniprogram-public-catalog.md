# M7-1 小程序公开目录只读接口

`GET /api/miniprogram/v1/categories` 返回启用中的分类，按排序值及 ID 升序；`GET /api/miniprogram/v1/products` 返回已上架且所属分类启用、至少有一款启用 SKU 与启用供应商的商品。列表可选 `category` 分类 slug、`page`（从 1 开始）、`page_size`（1–50，默认 20）。返回 `items`、`page`、`page_size`、`total`；无数据时返回空数组和零总数。

每件商品只公开编号、名称、副标题、分类 slug、启用 SKU 的最低积分价格（两位小数字符串）、是否有可售库存、启用主图 URL。库存状态来自 SKU 的 `on_hand_quantity > reserved_quantity`，仅供页面提示；实际下单仍由订单事务重新校验。未上架商品、停用分类、停用 SKU 或供应商不进入列表。采购成本、供应商、后台审计、会员身份和内部数据库 ID 不出现在响应中。

本轮接口无需登录，只提供公开目录；不复用后台 Cookie，也不开放激活、积分、订单或写操作。生产接入前需配置小程序合法域名、HTTPS、缓存和限流；域名与微信身份接入另行验收。无数据库迁移，真实业务库仅做只读预检，不为冒烟创建商品或订单；空目录响应是正常状态。

## M7-2 商品详情

`GET /api/miniprogram/v1/products/{product_public_id}` 通过公开商品编号读取已上架商品详情。只有启用分类、至少一款启用 SKU 且对应供应商启用的商品可见；未找到或不可见时统一返回 404。路径编号使用大写字母、数字和连字符，长度不超过 32；格式错误时返回 422。

响应包含列表页同名字段、商品说明 `description`、启用图片 `images` 和可售规格 `skus`。每款规格只给出 `sku_code`、名称、两位小数的积分价与是否有可售库存；图片只返回该商品上传目录下已启用的主图、轮播图和详情图路径。停用规格、停用供应商、停用图片、采购成本、供应商身份、库存绝对数量及内部数字主键均不返回。零库存的启用规格保留在列表供前端提示；库存及价格在实际下单时仍须重新校验。

该接口只读且无需会员登录，不建立后台 Cookie 会话。真实目录为空时详情测试使用不存在的商品编号并应返回 404；不得为运行态冒烟向真实库写入测试商品。详情页和微信真机设计将在后续阶段接入。
