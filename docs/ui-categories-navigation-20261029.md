# 首页8分类与四入口导航

用户已在微信开发者工具验收并认可积分页。本轮按已确认名称完成首页、分类页及导航联动，继续深绿、米白、暖棕积分色和圆角卡片。

## 客户看到的变化

- 首页搜索下方“探索好物”采用4列×2行图标入口，依次为居家日用、滋味零食、食品生鲜、首饰箱包、数码家电、全球美妆、厨房用品、母婴儿童。图标为本地样式绘制，沿用项目视觉语言；顶部宣传卡适当收紧，下方为两列独立排列的商品卡片。
- 点击任一入口直达分类页，并选中对应名称。分类页左侧为可滚动类目，右侧为商品列表；保留“全部好物”聚合入口，它不算第9个经营类目。
- 分类内可搜索、清除搜索、继续加载、失败重试；切换类目时列表和滚动位置重置，旧请求不会覆盖新类目。点击商品或“选规格”进入既有详情页，沿用选规格→加购物车→确认兑换流程。
- 底部四入口顺序为逛好物、分类、购物车、个人中心。个人中心的“我的积分”排在常用入口前方，以子页面打开；积分页移除底部一级导航，使用原生返回即可回到个人中心。
- 商品无图或加载失败有占位；空分类显示待上架，网络故障显示重试，不冒充空分类。

## 分类与真实数据边界

页面固定的分类键只用于导航，不假设与真实目录slug相同。进入分类页后按已确认名称匹配公开目录返回的唯一有效slug，再发送商品筛选请求；空slug、缺失或重名分类不会退化成“全部商品”。此轮没有向真实库创建类别、添加商品或调整微信服务类目。

首页继续使用原公开商品接口和排序，不伪造销量或热门排名，因此展示名称为“精选好物”。下方两列按接口顺序交错排列，保留分页顺序。

独立离线演示提供8类共9件虚拟商品及程序绘制占位图，便于逐类验收；没有真实售价、库存、商品素材、物流或供应商接入承诺。正式隐私批准与HTTPS标志、真实库0013、保存期限策略保持原状态。
