## 先买什么

推荐先准备 **1 台腾讯云 CVM 标准云服务器，4 核 CPU、8GB 内存**，用于测试部署。选择 CVM 是为了后续配置、网络和独立数据库的调整更灵活，并不代表轻量服务器无法运行本项目。CVM 调整配置仍受目标可用区库存和兼容性约束，通常需要关机重启；不能承诺无停机升级。[官方调整配置说明](https://cloud.tencent.com/document/product/213/2178)

先不为本项目直接购买 8 核 16GB。本轮 8 CPU 双进程相对 4 CPU 双进程，把集中兑换 P95 从约 7.3～7.8 秒缩短到 3.5～4.6 秒；增加 CPU 有帮助，但还有数秒等待，内存也没有出现耗尽。先用 4 核 8GB 完成实际部署与公网验收，再按目标机器的测试决定活动前是否升配。本机容器对照不能证明某种云主机的实际性能。

| --- | --- |
| 产品 | 云服务器 CVM，自定义配置 |
| 地域 | 上海，沿用当前测试部署候选 |

10Mbps 是测试起点，不是“100 人同时下载商品图”的带宽承诺。若每张图约 320KB，100 张共约 32MB，仅这批数据通过 10Mbps 出口的理论传输时间就约 26 秒，尚未计其他开销。更多 CPU 不会缩短这个带宽下限。集中活动前需要在实际网络上补测，并考虑商品图压缩、受保护图片独立存储与鉴权加速（仍须会员资格校验，不恢复公开直链）。

按月折算的服务器、磁盘和带宽合计控制在你的约 1,000 元预算内，并为备份和域名留余量。**已取得第一步截图报价970.80元/3个月，但尚未核对公网带宽及最终订单，不在这里承诺完整套餐价格。** 核对新购、续费和升级价格；若报价超过预算，先保存选配页面重新比较，不直接付款。[官方价格入口](https://buy.cloud.tencent.com/price/cvm)

历史预算比较（2026-11-05，非本次实时报价）：当日轻量官网列出通用型 4 核 8GB、180GB SSD、12Mbps、2,000GB/月流量套餐为 245 元/月；这只是公开标价，地区库存、实际订单和续费价格以购买页为准。轻量支持整体升配，不支持套餐降级。若 CVM 报价明显偏高，可改用它承载首期测试，但迁移和升级仍要演练。[轻量官方产品页](https://cloud.tencent.com/product/lighthouse) · [使用限制](https://cloud.tencent.com/document/product/1207/44376)

## 你按这个顺序配合

1. **已完成：实际运营主体选择与腾讯云企业认证。** 后续使用该公司控制的账号继续选配，无需重复认证。[官方创建实例教程](https://cloud.tencent.com/document/product/213/4855)
2. **进入服务器购买页，照上表选配。** [CVM 自定义购买](https://buy.cloud.tencent.com/cvm?tab=custom)。价格确认合适后由你在自己的账号中付款。
3. **选择公司域名。** 想好 2～3 个易记的名称，在[域名购买页](https://buy.cloud.tencent.com/domain)查看是否可注册；普通 .com 或 .cn 即可，先看首年及续费价格，不必买高价精品域名。域名与备案资料使用实际公司主体。
4. **准备备案。** [腾讯云备案入口](https://console.cloud.tencent.com/beian)。官方目前要求用于 CVM 备案的资源位于中国境内、有公网 IP、包年包月累计购买至少 3 个月，备案期间剩余有效期至少 1 个月；轻量也有对应的 3 个月要求。这是建议选 3 个月的原因。按平台实际提示完成公司资料和本人核验。[备案云资源条件](https://cloud.tencent.com/document/product/243/18908)
5. **把普通配置信息告诉我。** 云厂商、地域、服务器公网 IP、系统版本、域名和备案进度即可。密码、SSH 私钥和小程序 AppSecret 保留在你自己的设备上。

账户和服务器开通后，开发方继续配合安装 Docker、部署隔离 PostgreSQL 和应用、配置域名与 HTTPS、备份和恢复检查。现有部署方案已使用 Caddy 管理 HTTPS，暂不需要额外购买收费证书。

入口只开放 HTTPS/HTTP 所需的 443/80，SSH 22 限制为你自己的访问 IP；数据库 5432、应用 8000 和 OCR 8001 不对外开放。备案与平台配置未完成时，先通过受控连接做开发方测试。

## 买完后到能验收，还要完成什么

- 用服务器的真实 CPU、磁盘、带宽重复本轮压测，确认商品图和 OCR 同时运行时的体验。
- 域名、HTTPS 和微信合法域名配置完成后，后台上传商品图，在手机小程序中查看，并复验重启后图片、订单和登录。
- 把测试备份保存到服务器之外，在全新测试实例做恢复及账目核对。
- 小范围测试通过后再决定活动容量与是否升级；正式数据迁移、停写切换和微信发布另行安排。

域名备案和实名审核的完成时间由平台决定，不能承诺固定日期。云资源就绪后可以进入实际部署联调，无需等待所有远期功能开发完毕。
