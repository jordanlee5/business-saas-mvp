# 商城订单后台只读入口

M6-8 在左侧“积分商城”增加“商城订单”，供启用中的超级管理员和运营管理员查询订单。列表支持完整订单公开编号或会员公开编号精确检索、六种状态筛选和分页；没有真实订单时显示空状态。初审、复核、上传方、停用及权限未知账号无法通过导航或直接访问列表和详情。路由先验证身份，再建立数据库会话。

订单详情展示下单时的商品、SKU、供应商、积分价及人民币成本快照，以及订单状态和现有物流、完成、退款记录。详情读取时核对订单项、积分批次分配和主订单三组积分、成本及数量总额；已发货、已完成和已退款状态的对应记录缺失时失败关闭。列表用于查找，不代替详情证据复核。页面不展示手机号、车牌、微信身份、地址、积分批次编号或订单幂等键。

该入口只读，不提供取消、确认履约、发货、完成或退款按钮，也不创建真实业务库测试数据。后续写操作仍须分别调用既有原子领域服务，并在写入事务内执行完整资源和审计证据复核。继续使用 `0011_supplier_settlement_foundation`，本切片不新增迁移，也不改写现金返现业务。
