# 首页轮播图运营管理

2026-11-12，从 `f35deb0` 接续。代码和隔离验证完成，未部署到现有云端或本地测试工程；用户要求几项作业完成后再统一验收。

## 运营操作

后台“积分商城 → 小程序首页素材 → 首页轮播图”，与上轮八个分类入口共用权限入口。

1. 在五个素材位置中选择一个，上传图片，填写图片说明及排序数字。新素材默认停用，可先保存检查预览；确认后启用，也可明确勾选“保存后启用”。
2. 替换图片时选择新文件再保存。不选择文件即可单独修改说明、顺序、分类跳转和启用状态，原图片保留。
3. 排序使用 0–999 的整数，小的先展示；相同数字按素材编号排列。页面上方“当前展示顺序”展示已启用图片的顺序。
4. 用“启用 / 停用”控制展示；最多配置五张。停用后仍可在后台预览或重新启用，保留现有资料，不提供物理文件删除。
5. 点击目标可选择现有八个分类，或“仅展示”。不允许外链、自定义网页地址或绕过分类访问资格。

建议使用 1200 × 480 横图，文字和主要物品放中央；后台和小程序均按 5:2 居中裁切展示。支持 JPG、PNG、WebP，单张最大 5MB，检查真实格式后重新编码为最大 1600px WebP并去除原始元数据。图片说明用于后台识别及小程序无障碍描述，不会自动叠印到图片上。

## 小程序显示

保留绿色基调和现有首页布局。只有一张时静态展示，多张时每 5 秒切换，可手动滑动并暂停/继续。轮播控件显示当前页数；跳转仅允许既有分类。

小程序进入首页或下拉刷新时读取最新配置。停用、排序、替换没有向已打开页面实时推送；新请求立即按最新启停状态鉴权。没有启用素材、旧服务器没有接口、网络出错或所有图片加载失败时，回退原绿色品牌卡片。单张图片失败时跳过该张，其他可用图片继续显示；解码失败清理对应缓存，便于刷新重试。

素材加载与商品请求分别执行。离开页面、退出登录、切换账号或会员资格失效时，清除图片和轮播状态；较早的请求不能覆盖较新的刷新结果。原八个入口、商品搜索、分类与商品图片功能有回归验证。

## 权限和保存可靠性

- 运营员工/超级管理员可操作，其他角色无素材管理权限；数据库事务内再次检查操作者状态。表单有防跨站提交校验，操作日志与配置同时保存。
- 每个素材位置独立版本。旧页面的替换、排序或启停操作不能覆盖其他员工的新修改；PostgreSQL 两个运营并发修改已实际验证只有一个成功。
- 小程序配置及图片需要有效身份和当前会员资格；停用图片对会员返回 404，后台有权限的用户可预览。错误会员令牌不会回退到后台 Cookie。
- 图片路径只允许固定位置及服务器生成的文件名，检查目录边界，拒绝跨目录和符号链接逃逸。旧图片和未关联文件不能通过图片接口读取。
- 正常验证失败清理本次新文件；数据库提交回执不确定时保留文件并提示刷新核对，避免误删已经生效的图。旧文件暂时保留在备份范围，不增加自动清理任务。

## 数据、备份和后续部署

新增 `0020_home_banners` 及就绪检查，仅增加独立轮播表，不改写旧业务数据。表内有配置时禁止直接降级删表。抽取首页素材共同的图片编码函数，入口图片仍保持最大 640px，原有行为回归通过。

图片存放 `uploads/mall_banners`，现有容器将 `uploads` 链接到 `/data/uploads`，原备份已覆盖整个 `/data` 和数据库。因此无需改动加密、异机拉取、保留轮换或告警作业；本轮未重新做云镜像归档或冷恢复演练。旧镜像/旧备份恢复继续按已有精确镜像对应关系处理。

本轮未部署云端、未运行真实库迁移、未更新用户现有开发者工具工程；没有访问真实业务库、移动硬盘或任何私钥。后续统一验收前，在不占用现有测试的窗口准备独立候选环境，按既有恢复点与镜像归档要求安排版本和迁移。
