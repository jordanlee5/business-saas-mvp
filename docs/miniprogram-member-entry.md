# 小程序会员资格入口与图片缓存（2026-11-09）

从 `160b7cf` 接续第三轮客户端适配。前两轮的后台名单确认、微信绑定、服务端目录/图片/新兑换限制保持。本轮不改变公司主体、真实数据库版本或微信审核状态。

## 使用效果

- 首次打开首页、分类、商品详情深链或购物车，先核验资格。未登录只显示会员专属商城说明、主动微信登录、首次激活、本人订单/物流及权益申请入口。
- 复用原有激活资料核验与微信身份绑定。个人中心分别提示有效、停用、到期、尚未生效、未确认资格；故障显示重试，不开放商品。登录仍遵守已有隐私授权开关，正式开关未启用。
- 进入商品页面及兑换确认前核验服务端状态。停用/到期后，购物入口关闭，但会员身份仍可用于查询本人历史服务。未确认下单结果的关联编号保留，可继续查询；不因清理购物车丢失防重复下单的凭据。
- 商品原图和缩略图使用内存中的会员会话发送 Authorization 请求头，页面仅渲染下载后的本地文件。图片失败显示占位，详情可单张重试；不退回公开图片链接或把令牌拼在 URL 中。

## 清理与访问边界

图片位于 `wx.env.USER_DATA_PATH/mall-private-images` 专用缓存目录，使用随机时间/序号文件名，不落盘远程 URL 或令牌。下载最多并行 4 个，文件最多 80 个，长时间浏览淘汰较早使用的文件；较早图片如无法再读取，显示占位并可重新加载页面。页面离开、应用退后台、退出登录、切换会员或资格失效均清理图片。启动时清扫崩溃遗留文件，清理失败下次重试；不会遍历其他目录。

退出、切换会员、资格失效清空本机购物车并清除页面商品数据。存储删除失败时购物车停止读取，避免新账号读到旧购物车；重新登录重试清理。普通页面切换/退后台保留购物车的商品编号、SKU 编码、数量，重返页面从服务端重新取详情。下单恢复标记继续按会员隔离，不存收货地址、令牌或下单正文。

所有异步目录请求、下载和页面更新检查当前会话/页面代次；旧下载即使在清理后成功返回，也会删除其文件，不能重新填回页面。服务端每次请求实时校验资格；客户端使用服务端剩余时间设置到期清理，并在前台每 30 秒复核停用状态。弱网或系统挂起会延迟客户端探测，恢复页面会先重新核验。已经看过或截图保存的内容不能远程收回，不承诺停用瞬间抹去设备上的所有副本。

新增只读 `GET /api/miniprogram/v1/catalog-access`：本人 Bearer 会话认证，返回 `status` 和最多 900 秒的 `valid_for_seconds`，不返回名单、来源、其他会员或个人资料。成功/失败均禁止缓存。多个有效资格按最晚有效结束时间返回；零积分不取消浏览资格。资格异常不影响历史接口原有的本人校验。

下载调用与本地路径按[微信官方 API 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)核对。因为指定了 `filePath`，这是需要主动删除的用户目录缓存，而不是依赖系统自动回收的临时目录。
