# 供应商结算生成后台入口

M6-6 在 `/mall-settlements` 的只读列表上增加“生成待确认结算批次”表单。启用中的超级管理员和运营管理员可选择供应商及北京时间的开始、结束时间；结算区间为 `[开始, 结束)`，结束时间不得晚于实际生成时间。停用、初审、复核、上传方及未知级别账号既看不到表单，也不能通过 POST 路由生成。

浏览表单时生成独立随机令牌，使用仅随结算路径发送的 HttpOnly、SameSite=Strict cookie 与隐藏字段比对；缺失或不一致时拒绝写入。提交路由再次校验权限，并调用 M6-2 的 `execute_supplier_settlement_generation` 独立事务；请求字段不会直接修改批次或审计表。生成成功后跳转到只读详情；无新合格订单项、来源异常、重复区间无新增来源时显示失败原因，不创建空批次。

生成批次初始状态为 `PENDING_CONFIRMATION`，不可下载 Excel。只允许对已经完成且未退款的订单项生成结算，人民币金额仍使用历史订单项成本快照，管理员审计由领域服务在同一事务落库。历史供应商停用后仍保留既有完成订单的结算责任。

本切片不新增迁移，仍使用 `0011_supplier_settlement_foundation`。不提供确认、支付、撤销或冲销操作，不新增真实业务库的测试订单或测试结算。
