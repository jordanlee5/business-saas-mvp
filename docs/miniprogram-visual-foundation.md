# M7-9 微信小程序商城视觉样式基础

商城首页和商品详情共用 `miniprogram/src/app.wxss` 中的语义样式：`mall-surface` 表示白底圆角内容区，`mall-primary-action` 表示主操作按钮，`mall-points` 表示积分价格，`mall-muted` 表示辅助说明。页面自己的 WXSS 只保留布局、字号与页面特有状态。这些样式沿用既有品牌色和积分色，不新增组件库或构建依赖。

本切片不改变接口、数据结构、搜索、分页、商品详情、规格选择或库存查询行为。设计样式不是交易状态；价格、库存仍按公开只读接口返回的数据展示。上架商品和两款 SKU 的视觉回归在隔离 SQLite 副本验收，真实库保持只读。微信开发者工具同机模拟器验收涵盖空态、错误态、404、断服恢复、搜索、分类、商品卡与已选规格；后续仍需真机和合法域名验收。
