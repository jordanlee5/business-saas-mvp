# M7-18 小程序会员积分汇总页

“我的积分”页只在当前运行内存存在未过期的 M7-17 短期会话时，先以 `/auth/me` 再次验证会员身份，然后用同一 Bearer 调用 `GET /api/miniprogram/v1/points/summary`。页面仅显示服务端返回的两位小数字符串、积分批次数及北京时间最近到期时间。真实零余额可以显示为 `0.00`；访客与错误状态不伪造积分数字。

无会话的访客不发私有积分请求；会话 401 时清理本机令牌，显示重新登录入口。网络、服务或响应格式错误时隐藏所有旧积分并允许重试。离开页面后忽略旧请求结果；清理或替换会话后的响应也不能回写当前页面。令牌、微信 code 不进入页面 data、本地存储或日志。

本轮不新增登录、积分批次列表、激活、积分消费或数据库迁移。没有真实微信正式 AppID、HTTPS 合法域名与已绑定会员时，同机模拟器仅验收访客和无令牌拒绝；真实正向会员汇总记为 `DEFERRED`。不能把开发者工具的模拟请求当成真机身份验收。
