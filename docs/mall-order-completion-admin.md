# M6-11 商城订单确认完成后台入口

## 范围与权限

- 仅启用中的超级管理员、运营管理员可查看订单详情和确认完成。初审、复核、上传方及停用账号的直接 POST 在调用领域服务前拒绝。
- 只有 `SHIPPED`（已发货）订单详情显示确认完成表单。确认后详情展示固化的完成时间，不再提供按钮。
- 继续使用现有 `0011_supplier_settlement_foundation` 结构，不新增迁移、退款或订单取消入口。

## 完成流程

1. 管理员核对订单商品、数量及物流记录后提交确认。页面使用同源 HttpOnly、SameSite=Strict Cookie 与隐藏字段配对的表单令牌；HTTPS 下 Cookie 设置 Secure。
2. POST 验证账号权限和表单令牌后调用 `execute_order_completion`。领域服务在独立事务中锁定订单，重查确认履约、积分消费、库存出库及发货事实和唯一审计，并检查完成时间不得早于发货时间。
3. 首次确认同事务保存 `COMPLETED`、完成时间和唯一管理员审计；完全相同的重放不覆盖首次时间、不新增审计。状态或证据异常时失败关闭，页面显示错误。

已完成且未退款的订单只有在符合既有供应商结算服务的其他条件时才可纳入结算。真实业务库无商城订单时，列表空状态是预期结果；写入路径在临时 SQLite 和独立 PostgreSQL `_test` 中验收，不为页面测试创建真实订单。
