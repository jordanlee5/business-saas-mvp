## 第一轮：八个入口换图

后台“积分商城 → 小程序首页素材”（`/mall-home`）提供八个固定入口。运营员工及超级管理员可选择图片、上传保存、替换或恢复默认插画；审核人员及普通上传方无编辑权限。八个入口的名称、顺序和分类跳转不变，不用创建商品来保存装饰图。

建议上传 600 × 600 正方形素材，物品放中央；支持 JPG、PNG、WebP，单张最大 5MB。按实际图片格式校验并重新编码为最大 640px 的 WebP，去除原始元数据；拒绝 SVG、扩展名伪装、超大及损坏文件。长方形图片在入口内居中裁切，后台当前图片预览使用相同规则。

保存后，已部署对应客户端的小程序重新进入首页或下拉刷新读取新素材。未配置、旧服务器没有新接口、读取失败或图片解码失败时，显示原 CSS 插画；素材请求不会阻塞商品加载。后台名称与小程序名称固定，接口不允许外链图片或改写分类跳转。

后台表单有防跨站提交校验、操作日志和版本检查。旧页面不能覆盖别人刚保存的图，两个运营同时编辑只允许一个版本成功。普通验证或唯一冲突失败时清理新文件；数据库提交结果不确定时保留文件并要求刷新核对，避免已提交的图片被误删。替换和恢复默认不删除旧文件，但旧 URL 不再可访问，暂不增加自动清理任务。

图片和配置均不提供匿名访问：小程序每次读取需有效身份与当前会员资格，后台预览需素材管理权限。错误会员令牌不回退到后台 Cookie。图片走私有下载缓存，退出、切换账号、资格失效及离开页面时清除；迟到响应不能重新填回旧图片。
