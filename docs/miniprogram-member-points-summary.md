# M7-15 会员积分私有汇总

`GET /api/miniprogram/v1/points/summary` 仅接受 M7-14 签发的有效 Bearer 会话。
请求时重新核对微信绑定、AppID 和启用中的会员；后台管理员 Cookie 不授予访问权。

响应只含当前会员的可用积分、预占积分、批次数及最近一个仍有效且有可用余额批次的到期时刻。
金额为两位小数字符串；时间使用 `+08:00`。不返回姓名、手机号、车牌号、微信身份或业务单号。
无积分批次时返回 `0.00` 和空到期日。响应设 `Cache-Control: no-store`。

每次读取均用不可变流水核对账户及批次余额；缺失账户或缓存漂移返回通用 503，
不返回不可信余额，也不会写库、自动修复或执行到期维护。
运营仍须按既有独立流程维护已到期批次。本轮不接入小程序界面，
不配置真实微信密钥，也不把离线模拟验收视为真机登录验收。
