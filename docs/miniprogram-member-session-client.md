# M7-17 小程序会员会话入口

个人中心由用户主动点击微信登录，客户端用一次性 `wx.login` code 调用服务端 `POST /api/miniprogram/v1/auth/wechat-session`，拿到短期 Bearer 后再调用 `/auth/me` 验证，才显示会员公开编号。未绑定身份显示受控提示；网络、配置和服务错误不显示假会员数据。服务端需已配置相同正式 AppID、AppSecret 和会话签名密钥，临时测试号不能充当真实微信绑定验收。

令牌只存当前小程序 JavaScript 运行内存，不写入本地存储、页面数据或日志。过期前 30 秒不再使用；重新进入个人中心时持令牌校验服务端绑定和启用状态，401 时清理本地会话。页面离开后忽略旧请求结果，重复点击不并发发起登录。清除本机登录只删除客户端令牌，服务端签发的令牌仍按既有最长 15 分钟期限自然失效；此操作不构成服务端撤销。

本轮不接入积分汇总、批次页或激活流程。积分页保持访客说明，不将未验证积分显示为零。浏览器或同机开发者工具中，未配置真实微信身份的正向登录不可记为通过；以访客页面、受控失败状态和公开目录回归为运行态验收。真实 AppID、HTTPS 合法域名、绑定会员及体验/真机流程留待独立配置后验收。
