# 供应商结算确认后台入口

M6-7 在供应商结算详情页为启用中的超级管理员显示待确认批次的“确认结算批次”按钮。运营管理员可以继续生成和查看批次，不能确认；初审、复核、上传方、停用或权限未知的账号既不能看到按钮，也不能通过直接 POST 确认。

详情仍由 M6-4 只读服务复核来源订单、成本快照、批次合计与生成审计。确认前页面展示供应商、左闭右开结算区间、订单明细及人民币成本总额，并提醒管理员当前没有撤销或冲销流程。页面展示不代替提交时的复核。

详情为可确认账号签发随机表单令牌，以 HttpOnly、SameSite=Strict cookie 与隐藏字段传输。提交路由先复核账号与令牌，再调用 M6-3 的 `execute_supplier_settlement_confirmation` 独立事务，由服务锁定批次及来源证据，原子更新 `CONFIRMED` 状态、确认人、确认时间和唯一 `mall_supplier_settlement_confirm` 审计。来源不符时失败关闭；重复或并发确认返回既有事实，不重复写入。

成功后回到详情，确认按钮消失，显示确认记录，并按既有下载权限提供 Excel。确认并不代表付款；不新增支付、撤销、冲销或异常退款操作，不改写积分、库存、订单成本或现金返现数据。仍使用 `0011_supplier_settlement_foundation`，不新增数据库迁移。真实业务库无结算批次时只检查页面与权限，写入和重复提交在临时 SQLite 与独立 PostgreSQL 测试库验证。
