# M7-10 小程序 API 环境配置门禁

公开商品请求与商城图片使用同一 API 地址。仅当小程序版本是 `develop` 且运行于微信开发者工具 `devtools` 时，地址才为 `http://127.0.0.1:8000`。体验版、正式版以及开发版真机均要求 `miniprogram/src/config.ts` 中的 `HTTPS_API_ORIGIN` 为纯 HTTPS 域名。未配置时页面显示可重试的配置错误，不会向本机地址发请求或加载图片。

发布前由运营方取得可从手机访问的服务域名，配置有效证书，并在微信公众平台登记 request 与 downloadFile 合法域名。把 `HTTPS_API_ORIGIN` 设置成匹配的 `https://example.com` 形式，不允许端口、路径、尾斜杠、凭据、查询参数或 IP 字面量。该值仅为公开服务地址，不是 AppSecret、令牌或用户身份。域名变更须随构建审阅，并在真机检查分类、商品、详情和图片；同机模拟器及临时关闭域名检查不构成真机验收。

本切片不增加会员登录、会话或写接口，也不改数据库。后续登录接入时仍须在服务端验证微信 code、会话和授权范围，不能把小程序环境判断作为服务端身份校验。
