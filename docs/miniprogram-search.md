# M7-7 微信小程序商品搜索

首页搜索框调用已有的公开只读目录接口 `GET /api/miniprogram/v1/products?q=...`。点击“搜索”或输入法的搜索键才提交关键词；前后空白被去除，最多 80 个字符。空关键词恢复当前分类的全部商品，清除按钮同时清除输入与已提交条件。分类切换保留已提交关键词，分页、下拉刷新和失败重试也继续使用当前分类与关键词。编辑中但未提交的文字在切换分类时恢复为已提交的关键词，避免页面结果与搜索框不一致。

无匹配结果显示“未找到相关商品”；无搜索词且真实目录为空时保留“好物即将上架”。请求失败保留原有重试状态，后发起的查询不会被先前请求覆盖。搜索词通过 URL 编码传给现有接口，不进行模拟查询或写入业务数据。

这一切片仅修改小程序目录页面和请求参数，无新服务端路由、数据库迁移或秘密配置。同机微信开发者工具模拟器使用 `http://127.0.0.1:8000`；真机需可达的 HTTPS 服务和已配置的合法域名。真实目录为空时可验证搜索、清除、分类联动和请求 200，但命中已有商品、分页后续页须记录 `EMPTY`；不要向真实库制造测试商品。
