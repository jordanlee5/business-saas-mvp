# 商品目录写服务说明

## 1. 本切片边界

M4-2 在 `0004_catalog_foundation` 四张目录表之上新增受控领域写入口：

- 商品分类创建、编辑、排序和启停；
- 供应商创建、编辑和启停；
- 草稿商品创建、资料编辑、上架和下架；
- SKU 创建、资料、供应商、当前积分售价、人民币成本、预警阈值、排序和启停编辑；
- 每次实际写入对应的管理员权限校验和操作日志。

本轮不提供页面或 HTTP 写路由，也不实现商品媒体、库存余额/流水、Excel 导入导出、订单或小程序商品接口。服务不自行提交事务；未来路由必须在成功时整体提交，任一步异常时整体回滚。

## 2. 权限与审计

- 超级管理员和运营管理员可以管理商品目录及供应商；
- 初审、复核、上传方、停用管理员、不存在账号及未知权限级别全部拒绝；
- 分类、供应商、商品、SKU 的创建和编辑均使用已登记的商城审计动作；
- 商品上下架使用独立审计动作；重复请求到达相同状态时不写库，也不制造重复日志；
- 日志与目录实体使用同一数据库会话，调用方不得只提交其中一部分。

## 3. 稳定标识与输入规则

- 供应商公开编号使用 `SUP-` 前缀，商品公开编号使用 `PRD-` 前缀，均由服务端生成且编辑入口不可修改；
- SKU 编码创建时去除首尾空白并规范为大写，创建后不可修改，也不能改挂到其他商品；
- 分类 slug 规范为小写，只允许字母、数字和由单个连字符分隔的片段；
- 名称、slug、SKU 编码和供应商货号在既定作用域内保持唯一；
- 积分售价按两位小数四舍五入且必须大于零，人民币成本按两位小数四舍五入且不得为负；排序、低库存阈值必须为非负整数。

## 4. 商品状态和停用保护

- 新商品只能以 `DRAFT` 创建，不能由调用方指定为上架；
- 上架只允许 `DRAFT → PUBLISHED` 或 `UNPUBLISHED → PUBLISHED`；
- 上架时分类必须启用，且至少存在一个启用并绑定启用供应商的 SKU；
- 下架只允许 `PUBLISHED → UNPUBLISHED`，草稿不能借下架操作跳过首次上架；
- 重复上架已上架商品、重复下架已下架商品均视为安全无变化操作；
- 存在已上架商品时禁止停用其分类；存在已上架商品在售 SKU 时禁止停用对应供应商；禁止停用已上架商品最后一个启用 SKU；
- 草稿关联的分类、供应商可以停用，但必须先恢复有效目录关系才能上架。

## 5. 测试入口

```powershell
python -m compileall app
python -m unittest -v test_catalog_service.py test_mall_governance.py test_mall_domain.py
```

专项测试覆盖授权与越权、审计原子性、稳定标识、输入边界、唯一冲突、价格精度、草稿/上架/下架状态流转，以及分类、供应商和最后一个 SKU 的停用保护。
