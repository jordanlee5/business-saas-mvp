# 商品目录管理后台说明

## 1. 本切片范围

M4-3 将 M4-2 的受控商品目录写服务接入管理员页面：

- 左侧“积分商城”下新增“商品目录”入口；
- 在同一页面分区维护商品分类、供应商、草稿商品与 SKU；
- 编辑商品文字资料、当前积分售价、人民币成本、预警阈值、启停和排序；
- 通过专用操作上架或下架商品；
- 页面写操作成功后提交目录实体与管理员日志，失败时整体回滚。

本轮不新增数据库迁移，不实现图片上传、库存余额或流水、商品/库存 Excel、订单、小程序商品接口或删除操作。

## 2. 页面和权限

- 页面入口：`GET /mall-catalog`；
- 超级管理员和运营管理员可查看并操作；
- 初审、复核、上传方、未登录用户和未知级别账号不能进入页面；
- 未登录用户跳转登录页，无目录权限的已登录用户跳回工作台；
- 页面导航权限与路由权限使用同一 `can_manage_mall_catalog` 规则；
- 最终写入仍由目录领域服务重新校验数据库中的当前账号状态和审计动作权限，不能只依赖页面隐藏。

## 3. 操作顺序

首次使用建议按以下顺序：

1. 创建并启用商品分类；
2. 创建并启用供应商；
3. 创建草稿商品；
4. 为草稿商品创建至少一个启用 SKU；
5. 核对积分售价、人民币成本和供应商；
6. 执行上架。

商品没有启用且供应商有效的 SKU 时不能上架。已上架商品必须先下架，才能处理受状态保护的分类、供应商和最后一个启用 SKU。

## 4. 事务和错误边界

- 每次表单提交只执行一个领域写操作；
- 成功时由路由一次性提交目录变化和对应操作日志；
- 业务校验或权限失败时回滚，并把受控错误返回商品目录页面；
- 数据库唯一或关联冲突使用统一提示，不向页面暴露数据库异常细节；
- 未预期异常回滚后继续抛出，不能伪装成成功；
- 重复提交到相同状态时显示“当前数据没有变化”，不增加重复日志。

## 5. 展示边界

页面只读取已保存的分类、供应商、商品和 SKU，并先转换成只读展示快照。展示查询不会自动刷新状态、修复目录或写入数据库。SKU 页面中的“低库存阈值”只是 M4-1 已预留的当前配置；在库存表和流水切片完成前，页面不展示虚构的现存数量、可售数量或低库存结论。
