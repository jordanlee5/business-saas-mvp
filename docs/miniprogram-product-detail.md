# M7-6 微信小程序商品详情页

商品目录卡片打开原生详情页，调用已有的 `GET /api/miniprogram/v1/products/{product_public_id}` 只读接口。详情展示公开商品名称、图片、说明、积分价和已启用 SKU 的库存状态。图片限定在对应公开商品编号的上传目录。页面可下拉刷新；404 显示下架或不存在状态，网络或异常响应显示重试状态。当前不发起兑换、下单或任何数据库写入。

此切片没有新服务端路由、迁移或环境变量。目录为空时，不能从目录进入有商品的详情页；在微信开发者工具的**自定义编译模式**设置启动页面 `pages/product-detail/index`，启动参数 `id=PRD-NOT-FOUND`，可验证真实服务返回 404 的状态以及断开和恢复服务时的错误、重试状态。正常商品图、规格及卡片跳转只在已有真实上架商品时人工验收；若真实目录为空，记录 `EMPTY`，不制造测试商品。独立测试库的自动化回归覆盖服务端已有商品的详情契约。

微信开发者工具导入隔离临时副本的 `miniprogram/`，避免编译生成文件混入原仓库。`http://127.0.0.1:8000` 仅适用于同机模拟器；本地调试可临时关闭工具的合法域名检查。真机预览与正式发布需可达 HTTPS 地址及已配置的 request/downloadFile 合法域名。退出前恢复本地调试的域名校验设置，不将模拟器验收记录为真机验收。
