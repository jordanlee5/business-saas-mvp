# 供应商结算只读后台

M6-5 在 M6-4 内部服务之上开放 `/mall-settlements`，让启用中的超级管理员与运营管理员查看结算批次、证据复核后的明细及已确认批次 Excel。初审、复核、上传方或停用账号无法浏览列表、详情或下载。

列表支持结算编号、供应商公开编号或名称检索，按待确认、已确认筛选并分页；详情重查来源完成订单、未退款事实、快照、汇总和生成/确认审计。出现证据异常时页面不会显示该批次的明细。列表、详情不写入结算或审计记录。

详情只有在批次 `CONFIRMED` 时提供下载按钮。下载路由再次核验账号及批次，复用 `execute_supplier_settlement_export` 在独立事务内生成工作簿并写入一次导出审计，失败时不交付文件。下载文件名只使用可信的数据库批次 ID 和导出时间，避免从历史编号拼接 HTTP 头。

本切片不新增表或迁移，不提供生成/确认后台表单，不记录供应商已收款，不提供支付、撤销或冲销操作。会员、地址和物流信息不出现在结算页面和工作簿中。
