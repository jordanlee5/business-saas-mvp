# M7-24 商城权益激活码首次签发入口

本轮在商城业务详情中增加**首次签发**入口。仅启用中的超级管理员与运营管理员可看到表单并提交；初审、复核、上传方和停用账号不能执行。服务端重新核验角色、表单令牌、商城渠道、批次已承接、业务待激活、领取截止时间、业务匹配信息及未生成积分权益。既有凭据一律拒绝重新签发，避免重复点击使已交付的激活码失效。重签、撤销和自动交付不在本轮。

签发复用既有一次性码服务：数据库仅保存随机盐和 PBKDF2-SHA256 摘要；签发事实与 `mall_activation_issue` 管理员审计同一事务提交，审计不含明文。成功页仅在提交响应中显示一次明文，并设置 `Cache-Control: no-store, private`、`Pragma: no-cache` 与 `Referrer-Policy: no-referrer`。返回详情或刷新后不再提供明文。页面提示管理员通过已确认的安全渠道交给上传方，由上传方安全交付客户；系统本轮不代发、不把明文写入邮件、日志或导出。

人工验收只检查真实业务库上的详情**只读页面和权限**，不在真实业务库为演示签发激活码或创建商城业务。正向签发、重复提交、审计回滚和角色隔离在临时 SQLite 测试中验证。微信真机正向激活仍受正式 AppID、AppSecret、HTTPS 合法域名、安全交付与入口限流等部署条件约束，未具备时记为 `DEFERRED`。本轮没有数据库迁移。
