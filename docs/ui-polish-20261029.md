## 本轮改动

- 订单列表原样展示`2026-10-29T06:05:42+08:00`的问题：新增仅用于展示的`createdText`，呈现“下单时间：年月日 时分秒（北京时间）”，保留原始接口时间与排序。
- 订单与积分共用明确时区的时间格式化；UTC和其他偏移的同一时刻都转换为北京时间，已是+08:00的不重复加八小时。不带时区或无法解析的值不猜测手机时区，显示“时间暂不可用”。
- 离线演示过去直接在UTC钟面后加`+08:00`，使订单及积分显示落后八小时。生成时间先转换到UTC+8钟面，再加时区；初始积分、下单、取消、退款等共用修正。只影响重新生成的虚拟数据，不改写真实历史时间。
- 商品详情底部改为“选好商品和规格后，可前往购物车确认兑换。”，去掉已过时的阶段提示。
